所定判定、post-pin、必要な四軸の確認と確定記録を**同候補・同系列・同slot／attempt（該当時は同generation）**で揃える。初回SL01は前slotなしと固定し、後段で前slotが存在するのに記録がないケースとは区別する。前slotの終端未確認は、次slotを試しに起動して調べる理由にしない。時計不明や締切到達で期限内と確認できない場合はUnknown／調査保留として、先行理由・未確認軸・責務だけを保持する。遅いexit／EOF／receiptは解放の追記に限り、元判定や同系列の閉鎖を覆さない。

## 4 cleanup予約：通常枠に貸さない

系列固有の最初の副作用直前に、同一の単調時計で `T0` を一度だけ採る。`D_obs = T0 + B_obs`、`D_end = D_obs + R_cleanup` とし、各起動直前の `t_i < D_obs` と `t_i + W_i < D_obs` をともに要求する。等号、加算不能、clock不明・逆行、取消、許可／pin失効では起動0。成立しても当該slotの確認は `min(t_i + W_i, D_obs)` より前であり、既存の個別期限は延長しない。早期終了や停止で起点・締切を更新しない。

| 配賦 | 起動前に揃える根拠 | 起動0／閉鎖後に許す範囲 |
|---|---|---|
| `W_i`／通常slot | 固定site・試行数・件数・通過／保持bytes・処理／待受上限、起動手渡し・必要観測・post-pin・通常終端の上界。slot間の入場確認費は系列の手渡し費として事前配賦 | 未導出・承認なし・残量不足で起動0。入場拒否の確認費だけを所定の手渡し費に計上し、未起動slotの効果操作は開始しない（FP11） |
| `R_cleanup`／系列に一度 | 部分生成・未確認を含む到達可能な失敗prefixと、系列共有物の最終回収の上界。R1〜R7の有限上界の合計以上を予約し、`D_obs` からの各累積cutoffを事前固定する | 予約不足・権限や保全先の未確定で起動0。正常slotごとに再確保せず、既消費を重ねて計上しない。系列閉鎖後は既承認の残存責務だけ扱い、観測再開・枠の再配分・新規試行をしない |
| R1〜R4／停止・退出・stdio・棚卸し | 同対象の停止権限、T01〜03に対応する観測、生成済みpin・所有／借用台帳の照合上限。exit捕捉・drainは起動後から並行、R番号は確認期限の順 | 対象／所有／退出が不明なら権限外の停止・削除なし。R4でも安全に確認できない対象は未確認のまま上位へ |
| R5〜R6／上位受理・固定discard | 同系列／slot／attemptの先行上位枠、監視側・runner喪失後の同枠照会、同じ受理票と唯一の処理権、独立空確認・各費目の上界 | 受理不明なら許可済みの同枠照会のみ。未終端・同一性不足・借用未退役・受理未確認では削除0。試行後の結果不明で再削除しない |
| R7／最終判定の封印 | 最後の確定prefix・四軸・先行理由・残存責務・上位保持先の固定欄、封印の上界。異常時もR7を他費目に使わない | R7開始時の不足を待ち直さず未確認として封印。`D_end` 到達・clock／owner喪失で封印不達なら、先行上位枠に残る確認済み範囲のみを根拠にUnknown。次slot起動0・遡及変更なし |

数値は記入しない。既存の個別timeout、通常並列の元5秒・既定並列度、旧比較の60秒、製品期限、過去の所要時間は、この予約の根拠や代替値ではない。予約は「期限内に判定または未確認として引き渡す」ためのもので、強制停止や必ず全資源を解放できることの承認ではない。

## 5 判定票に残す項目と今回の結論

- 判定票には、系列／候補の指定、G01〜04の証拠参照・承認範囲、当該段のpinとまだ生成していないpinの区別、予定slot／直前slotと終了四軸、通常枠とcleanup予約の根拠、最初の停止理由と未確認責務の参照を分けて残す。対象・承認・証拠・上界・責務先のうち、その段で必要な一つでも欠ければ、その段の起動は0。先行操作が既に消費済み・未確認なら、その記録を0で上書きしない。
- 確認の境界は、たとえば「tarball未生成でもbuild前のpinが揃えば、その不足だけでbuildは拒否しない」「tarball digest不明なら展開0」「runnerだけ終了なら次slot 0」「通常枠が等号なら、予約が余っていても起動0」「封印不達・保全応答不明は再実行0」。先行停止後は予約内の権限に限り、消費済み・未到達・未確認を別々に残す（FP01／02／04／08／10〜12）。
- 現時点は候補未確定・承認未了のため、**SL01から起動0**。EV／QAの静的確認や限定対照の結果が後日得られても、その範囲を越えて採用しない。候補入場、全P判定後の候補受入、旧試験切替・公開は別判断であり、AP06や閉鎖条件・Unknown・調査保留はどの段階でも自動解除しない。
