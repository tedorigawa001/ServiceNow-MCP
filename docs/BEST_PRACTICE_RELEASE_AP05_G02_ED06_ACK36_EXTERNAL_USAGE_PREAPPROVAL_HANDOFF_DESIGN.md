## 1 個別承認票に渡せる証拠と結合条件

将来、別途許された範囲で提示された最小限のメタ情報を、段階1→2→3→4の順で照合する。受け渡すのは、同じ資料・指定箇所・対応行に結び付く証拠の**匿名参照と確認範囲**であり、本文や外部利用の判定結果ではない。

| 段階／承認票の欄 | 渡す証拠 | 次段階に進める条件／止める例 |
|---|---|---|
| [1. 対象資料](BEST_PRACTICE_RELEASE_AP05_G02_ED06_ACK36_EXTERNAL_USAGE_STAGE1_MATERIAL_SCOPE_DESIGN.md) | 票内の匿名資料ID、資料種別・由来・最小箇所・必要理由、対応行。利用側抜粋と旧版の実解決記録の対応根拠は、呼出し箇所と利用時点を分けて示す | 同じ呼出し箇所と同じ利用時点の両方が対応する。資料未指定・片側だけ・関係不明なら停止。repo内比較と任意の申告要約は別欄で、必須証拠の代用にしない |
| [2. 提供権限の証拠](BEST_PRACTICE_RELEASE_AP05_G02_ED06_ACK36_EXTERNAL_USAGE_STAGE2_PROVISION_AUTHORITY_DESIGN.md) | 提供側の確認役割・根拠参照、委任・第三者由来部分の対象範囲、提供・閲覧・記録・保持それぞれの目的、対象版、役割、制限・有効期間と失効／取消の確認参照 | 段階1と同じ箇所に有効な権限が及び、予定する全操作が許可範囲内。操作間・別版間の流用、欠落、期限満了・取消は停止。提供側の閲覧許容は別途の閲覧承認ではない |
| [3. 版固定の証拠](BEST_PRACTICE_RELEASE_AP05_G02_ED06_ACK36_EXTERNAL_USAGE_STAGE3_VERSION_PIN_DESIGN.md) | 元資料版／元箇所、閲覧予定の秘匿化済み抜粋版／抜粋箇所との対応、抜粋自体の不変参照または内容同一性の根拠。別欄に、当時の旧パッケージ版・実解決先（型／実行時の別）と既存記録の参照 | 元資料と抜粋が対応し、段階2で許される版・範囲と一致し、旧版の実解決先が段階1の組に結び付く。可変参照・差し替え可能な添付、別時点の解決記録、依存宣言・lockだけでは停止 |

同じ匿名IDや版ラベルが並ぶことは、結合の証明ではない。票に示すのは、**対象・対応行 → 有効な操作別許可 → 同じ固定抜粋版・指定箇所 → 同版に対する秘匿化確認**の根拠。元資料版、固定抜粋版、旧版の実解決先は別参照のまま残す。別の呼出し箇所・時点・版の資料を組み合わせて不足を埋めない。

## 2 審査に渡すものと閲覧0の判断

| 状態 | 個別承認票へ渡すもの | 閲覧の扱い |
|---|---|---|
| 実資料未指定・証拠不足・不一致 | 最初に止まった段階、許された匿名参照、不足・不一致理由と未確認範囲のみ。後続は未到達とし、合格欄や外部利用の結論欄を埋めない | **閲覧0。審査に進めない。** 原本・本文・プレビュー・リンク先を開いて補わず、取り寄せ、照合値の算出、再加工も行わない |
| 段階1〜4の証拠が揃い、すべてが同じ対象・固定版・範囲に結び付く | 段階別の匿名証拠参照、照合した範囲、審査に進める旨。閲覧承認欄・外部利用の結論欄は未記入 | **閲覧0。進めるのは個別承認の審査まで。** 提供側の許可や資料適格性だけでは開始しない |
| 別途の閲覧承認も同じ固定版・指定範囲に揃う（将来条件） | 別途の承認者・有効な承認参照と許可範囲、閲覧担当・手段・期限・上限、要約の記録／保持の許可・条件、停止時の引受先 | 許可された担当が、指定された手段・範囲内に限って将来の開始を判断する。本MDは承認・開始指示ではなく、今回は閲覧0 |

上の「審査に進めない」は閲覧に向けた適格審査への受渡しを指す。不足理由を所定の票に返すことと、閲覧承認を求めることは分ける。提供側の条件と別途の閲覧承認の範囲が食い違う場合、承認票に承認参照があっても閲覧0。要約の記録／保持条件や停止時の引受先が未確定の場合も同じ。

- 差し替え・再秘匿化・対象範囲変更は別の対象として再申請し、段階1から照合し直す。失効・取消・不一致が分かった場合、旧判定や旧許可を流用しない。将来の承認後でも、以後の閲覧・転記を停止し、許された範囲で停止理由と未確認範囲を引き継ぐ。無断で再開・保存・削除しない。
- 票や受渡しメモに原本・本文、認証情報・機密パス・個人識別情報、匿名対応表を持ち込まない。未確認を「指定範囲で該当を観測せず」「外部利用なし」「影響なし」に読み替えない。この審査・閲覧承認は処遇、旧保証の代替、候補検証・起動、公開の承認を兼ねない。
