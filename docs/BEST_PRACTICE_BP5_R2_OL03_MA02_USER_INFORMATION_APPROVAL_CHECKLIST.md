## 1. 記入前の注意

[GnuPG固定候補・合成隔離試験計画](BEST_PRACTICE_BP5_R2_OL03_MA02_GNUPG_BASELINE_ISOLATION_DESIGN.md)に対応する票。draft-0.1は未記入票として作成し、draft-0.2で利用者本人が本チャットで順に回答したI01〜I05を記録した。最初は既存環境や信頼元の**有無・候補だけ**を記入する。「なし」「不明」でよい。未取得のhashや新しい鍵をこの票のために用意する必要はなく、新規取得・導入・設定はしない。

情報の提示、候補の選定、操作の承認、鍵の信頼承認、実行結果はそれぞれ別。I欄のチェックは回答受領だけを示す。E/A/T欄は未チェック、承認/実施結果欄は空欄であり、空欄を同意・不備なし・Knownと解釈しない。この文書の保存/コミットや、設計書への了承を実行許可へ広げない。

チェックだけで自動実行しない。実際に操作する前に、利用者本人の明示指示と対象/範囲/期限/前提が一致することを確認し、承認根拠を記録する。agentによる記入や候補資料の記述を利用者の承認と扱わない。

5項目Unknown、全体受付無効、telemetry保留、APPROVED_REGISTRY=None、通常v2 Unavailable/gate92、DER/absence停止を維持する。本票は導入・起動・実装・鍵承認/import・archive取得/展開・実機操作・設定変更・permit発行・担当者への連絡を許可しない。Pushは本票の承認対象外で、引き続き行わない。
