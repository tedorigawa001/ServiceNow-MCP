## 依頼本文案

件名：Inbound API Integration Usageの利用不可に関する読み取り調査のお願い

maint権限をお持ちのご担当者様

PDI（dev441827）のInbound API Integration Usageで「Inbound Integration Usage is not available」と
表示された事象について、実施承認後、既存の正当な権限の範囲で以下の読み取り確認をお願いします。

確認項目：

- telemetry接続設定の存在・選択される設定・HTTPメソッド・接続先形式の妥当性。
- `api_headers`の空値/JSON妥当性と、既存のヘッダー解析エラーとの関係。
  このエラーはHTTP応答解析とは別で、最終失敗原因とはまだ断定していません。
- 既存ログに残る元の通信失敗段階・HTTPステータス・応答解析エラー。
- `this.logger`参照による二次エラーの有無。元のエラーとは分けて確認してください。

証拠は[確認・証拠取得計画§5の提出票](BEST_PRACTICE_BP5_TELEMETRY_MAINT_EVIDENCE_PLAN.md)に、
確認結果・件数・タイムゾーン付き時刻・標準クラス/メソッド/行番号を記入してください。
時刻のタイムゾーンが不明ならその旨を、確認できない項目は「未確認」と記載してください。
同じ秒のログだけで同一要求と判断せず、要求単位の相関の有無を明記してください。

資格情報、ヘッダー名/値、接続先URL、応答本文、生ログ、HAR、スクリーンショット、設定exportは
提出せず、識別子は仮名化してください。提出前に秘密を含まないことを確認し、
承認済みの提出先だけに共有してください。判断できない内容は値を出さず「withheld」としてください。

権限追加・昇格・偽装、トークン発行、設定/コード変更、ログ有効化、再現通信は依頼範囲外です。
ACLを別経路で迂回せず、既存情報で確認できなければその制約をご報告ください。
